# Estagiagros

Requisito: Python 3.9 ou mais novo (nada para instalar).

    python app.py --seed      # 1ª vez: cria o banco com dados de demonstração e inicia
    python app.py             # nas próximas vezes
    # abra http://127.0.0.1:8000

Contas de demonstração (senha demo12345): aluna@exemplo.example e contato@fazendaboasafra.example
(o `--seed` lista todas). Para uso real, não use `--seed` e ponha o servidor atrás de HTTPS.
